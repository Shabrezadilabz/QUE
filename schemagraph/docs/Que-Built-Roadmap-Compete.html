2. What we have built (inventory)

Everything below is implemented and demoable in the current Que stack (Vite SPA + Express API + Postgres/pgvector).

Built Access & tenancy

  • Create account / sign in; optional OIDC SSO (PKCE, JWKS, hash token delivery)
  • Create / switch workspaces; invite members; pending invites; role change / remove
  • Roles: viewer → member → admin → owner (last-owner protections)
  • In-app onboarding roadmap dialog (Skip / Next / Done; reopen via ?)

Built Sources, schema, joins

  • Connectors: PostgreSQL, Databricks, Snowflake, Excel/CSV, Mongo (fixture and/or live)
  • Encrypted credentials at rest (__enc AES-GCM)
  • Sync → canvas graph; join inference; Promote / Reject HITL; stitch session
  • Optional Databricks query-history assist for joins

Built Privacy, AI, chat

  • Schema-only defaults; sample scrub; policy toggles in Settings
  • Chat skills + optional LLM/RAG; capped sample previews
  • Job draft from chat → Save to Jobs with deep-link navigation

Built Jobs & ship path

  • Notebook cells; dry-run; capped live validate (read-oriented)
  • Export JSON / SQL / dbt / optional dbt-PR to GitHub
  • Contract freeze; drift gates; HMAC attestation + verify endpoint

Built Security & ops spine

  • Prod boot gates (secrets, CORS, no auth bypass); health endpoint
  • Automated diligence / unit / smoke / Playwright browser E2E
  • Docs: Feature Guide, Local Setup, Manual Test Plan, Investor Diligence PDF
POC success definition
N promoted joins + 1 attested export (JSON or dbt) + precision/recall on their golden join pairs — not “catalog coverage %.”
Partial / demo risk
Join evidence UX on every edge; Settings billing stubs; live warehouse quality varies by customer network/tokens.

5. Future — compete with Atlan / Collibra / Alation / DataHub

“Replace Atlan/Collibra this quarter” is a category claim. It requires becoming a catalog + governance platform, not only a join-shipping appliance. Build only if strategy expands — after wedge revenue.

Not this quarter Do not market glossary depth, stewardship workflows, or full column lineage you have not built. Competitors already lose deals on incomplete lineage — overclaiming is fatal.

Future A Catalog breadth (parity table stakes)

  • Connectors at scale: BigQuery, Redshift, Synapse, Glue, Kafka, S3 lakes, Airflow / OpenLineage ingest
  • Asset types beyond tables: dashboards, metrics, ML features, pipelines as first-class nodes
  • Search ranked by popularity/usage; duplicate dataset detection
  • Business glossary + term↔table linking; stewardship (certify, expire, owner queues)
  • Automated multi-hop column lineage across SQL + dbt + BI
  • Quality / profiling signals (null rates, freshness) — privacy-gated

Future B Governance & collaboration (Collibra / Alation territory)

  • Policy packs: PII tags, retention, access-request tickets
  • Workflow engine: approvals, RACI, scheduled digests
  • Integrations: Jira / ServiceNow, Slack / Teams
  • Domain / data-product modeling; steward UX mode without killing the DE wedge

Future C AI enterprises will trust

  • Grounded answers with citations to lineage edges + owners
  • Hallucination eval harnesses; schema-only guarantees in contract language
  • Optional “propose PR” with mandatory HITL (keep Que’s DNA)
Honest future claim (only after Phase 3 depth): “Works as catalog + join-shipping platform beside or instead of lighter catalog installs” — still not a casual “replace Collibra overnight” soundbite.

6. Future — Big-4 audit bar multi-tenant SaaS

Unattended multi-tenant SaaS sold into Big-4-audited enterprises needs a control plane + evidence pack, not just features. Que is not there yet.

Not yet Do not claim SOC 2 Type II, SCIM directory sync, HA isolation proof, pen-test pack, or contractual uptime SLAs until evidence exists.
AreaMust add to reach the bar
Identity SCIM 2.0; org-wide SSO enforce; break-glass; session revoke UI; scoped API keys; optional CMK
Compliance evidence SOC 2 Type II (then ISO if needed); annual pen-test; SBOM; immutable audit export; DPA / residency options
Tenant reliability Hard isolation + automated isolation tests; HA Postgres; backups/PITR; DR RPO/RTO drilled; queues; rate limits
Ops & delivery Observability + status page; on-call; SLAs; VPC / private link; optional self-hosted gateway; admin console
Big-4 buyers ask for evidence, not slideware. Budget calendar time for audit — not only engineering features.
