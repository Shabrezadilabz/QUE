Que schema-only attestation

Customer / CISO one-pager · generated from product guarantees in code · Jul 2026

Policy: schema-only
Que uses schema metadata and capped column samples only. Raw warehouse rows are not centralized for model training or chat prompts.

Guarantees (enforced in product)

  • No full-table extracts stored for AI training
  • Chat prompts use schema context packs only
  • Live validate / dry-run respect hard row caps (samples ≤10 · validate ≤20)
  • Human promote/reject owns join truth — AI never auto-promotes
  • AI SQL drafts prefer the accepted-join graph; inventing join paths is blocked
  • Every export carries a machine-readable attestation + fingerprint in export_audit_events

What leaves the customer network

  • Optional LLM BYOK: schema packs + product docs — not warehouse dumps
  • Optional GitHub export: SQL / dbt / attestation JSON to the customer’s repo
  • Optional webhook: contract/drift envelopes (metadata events)

Diligence hooks

  • npm run test:diligence — join golden-set + privacy red-team
  • CI workflow: .github/workflows/que-diligence.yml
  • Attestation module: api/src/exporters/attestation.js

This page is sales ammo for Legal/Security — not a substitute for a customer SOC2 or DPA.
