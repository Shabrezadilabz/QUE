## Step 1 — Postgres (Neon) ✓ do first

Already created Neon? Run:

```powershell
npm run bootstrap:sportedge-pg
```

Verify in Neon SQL Editor:

```sql
SELECT COUNT(*) FROM customers;   -- 2500
SELECT COUNT(*) FROM orders;      -- 3500
SELECT sku FROM products LIMIT 3;
```

Create **read-only user** for Que (Vercel) later:

```sql
CREATE USER que_reader WITH PASSWORD 'strong-password';
GRANT CONNECT ON DATABASE neondb TO que_reader;
GRANT USAGE ON SCHEMA public, finance TO que_reader;
GRANT SELECT ON ALL TABLES IN SCHEMA public, finance TO que_reader;
```
