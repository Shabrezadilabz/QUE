I need to build a materialized view combining @events_raw and @users_dim to track daily active sessions per region. The /skills optimize flag is active.

I've designed a materialized view schema based on the @events_raw stream and @users_dim table. Using the /optimize skill, I've partitioned by event_date and clustered by region_id to minimize scan overhead during your dashboard queries.

database SQL (ClickHouse Dialect) 
CREATE MATERIALIZED VIEW prod_analytics.mv_daily_regional_sessions
ENGINE = AggregatingMergeTree()
PARTITION BY toYYYYMM(session_date)
ORDER BY (region_id, session_date)
AS SELECT
    toDate(e.timestamp) AS session_date,
    u.region_id,
    uniqCombined(e.session_id) AS total_unique_sessions,
    count() AS total_events
FROM raw_data.events_raw e
INNER JOIN dims.users_dim u ON e.user_id = u.user_id
WHERE e.event_type = 'session_start'
GROUP BY 
    session_date, 
    region_id;

Notice the use of uniqCombined() instead of COUNT(DISTINCT) for probabilistic counting, which is ~3x faster for large cardinality in this engine.
