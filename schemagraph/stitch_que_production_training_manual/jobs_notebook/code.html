Daily User Retention Calculation

This query calculates the rolling 7-day and 30-day retention metrics based on event logs. Requires the clean events table to be updated prior to execution.

SQL • Main Query 
WITH active_users AS (
  SELECT 
    user_id,
    DATE(event_timestamp) AS activity_date
  FROM {{ ref('stg_events_clean') }}
  WHERE event_type = 'user_login'
  GROUP BY 1, 2
)
SELECT * FROM active_users LIMIT 100;
