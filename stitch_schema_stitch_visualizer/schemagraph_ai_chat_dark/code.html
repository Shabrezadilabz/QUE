I've analyzed your database schema. Joining transactions with customers using customer_id. Filtering for is_premium = TRUE and region = 'EMEA'.

SELECT 
    DATE_TRUNC('month', t.transaction_date) AS revenue_month,
    SUM(t.amount) AS total_revenue
FROM transactions t
JOIN customers c ON t.customer_id = c.id
WHERE c.region = 'EMEA' 
  AND c.is_premium = TRUE
GROUP BY 1
ORDER BY 1 DESC;
